🚀 最快开始方式（4 步，5 分钟）
═══════════════════════════════════════════════════════════════

【第 1 步】打开命令提示符
─────────────────────────
Windows: 
  1. 按 Win + R
  2. 输入 cmd
  3. 按 Enter

Mac/Linux:
  直接打开终端

【第 2 步】进入项目文件夹
─────────────────────────
假如你把文件夹放在桌面，就输入：

cd Desktop\oil-drop-complete-guide

（把 Desktop\oil-drop-complete-guide 改成你的实际路径）

【第 3 步】安装依赖
─────────────────────────
复制这行命令，按 Enter：

pip install -r requirements.txt

（会安装 requests, tqdm, pyyaml 三个库）

【第 4 步】运行下载脚本
─────────────────────────
复制这行命令，按 Enter：

python download_datasets.py

然后按照菜单操作：
  - 选择 1（一键下载所有数据集）
  - 等待完成

❓ 常见问题
═══════════════════════════════════════════════════════════════

Q1: 找不到 python 命令？
A: 
  1. 重新安装 Python
  2. 安装时勾选 "Add Python to PATH"
  3. 重启电脑

Q2: 提示 "ModuleNotFoundError"？
A: 
  运行这个命令：
  pip install -r requirements.txt --upgrade

Q3: 下载失败了？
A:
  1. 检查网络
  2. 重新运行脚本
  3. 脚本会继续下载未完成的文件

Q4: 需要多大空间？
A:
  至少 2GB（建议 5GB）

Q5: 数据下载到哪里了？
A:
  项目文件夹中的 data/ 子目录
  运行 python check_data.py 查看统计信息
